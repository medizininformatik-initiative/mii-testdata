# synthiFHIR

[synthiFHIR](https://github.com/medizininformatik-initiative/synthiFHIR) generates synthetic FHIR R4 test data from Excel, CSV and Synthea sources. The web workbench supports configuration, bulk generation, downloads and FHIR server uploads.

- [Setup and usage](https://github.com/medizininformatik-initiative/synthiFHIR/blob/main/README.md)
- [Current starter workbooks](https://github.com/medizininformatik-initiative/synthiFHIR/tree/main/input)
- [Workbench documentation](https://github.com/medizininformatik-initiative/synthiFHIR/blob/main/web/README.md)

This directory also contains `FHIR_Testdatengenerator_Vorlage.xlsx`. Use the starter workbooks linked above with the current generator.
