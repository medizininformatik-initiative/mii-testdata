{% comment %} structure-tabs — an official-FHIR-spec-style tabbed rendering of ONE artifact's structure inside a NARRATIVE page (Structure / Differential / XML / JSON), backed by the fragments the IG Publisher generates anyway. Bootstrap's tab JS is already loaded by the base template, so the tabs work without extra assets. Usage in input/pagecontent/.md (one line, outside comments): {% raw %}{% include structure-tabs.html artifact="StructureDefinition-mii-pr-dokument-dokument" %}{% endraw %} Optional parameters: lang="de" — localizes the tab labels (default: en). Pass the language of the page variant the file belongs to (German mirrors pass "de"). id="x" — unique suffix when the same artifact is tabbed twice on a page. The four fragments -snapshot / -diff / -xml-html / -json-html must exist under _includes — the publisher generates them for StructureDefinitions. Verify before use (ls temp/pages/_includes/ after a build): ONE missing include fails the entire Jekyll run. Prefer this include over pasting fragments below each other; prefer a plain link to the artifact page when the narrative does not need an inline rendering at all.
